# CLAUDE.md

Guidance for AI assistants (and humans) working in this repository.

## What this package is

`scatools` calls copy-number alterations (CNAs) from single-cell ATAC-seq
(scATAC) data. It is an R package built on Bioconductor's
`SingleCellExperiment` (SCE) container. The method adapts single-cell DNA CNV
techniques (Ginkgo-style modal-quantile GC correction, HMMcopy ideal-bin
filtering, CBS segmentation, copyKit `mergeLevels`) to the sparse, biased
signal of scATAC fragment counts, and adds an allele-specific (BAF) path.

## Core pipeline (depth-based CNV)

`run_scatools()` (`R/run_scatools.R`) is the top-level wrapper. The flow:

1. `bin_atac_frags()` (`R/bin_utils.R`) — tabulate fragment cut-sites into
   genomic bins (data.table), write a 10x-style sparse matrix. Both ends of
   each fragment are counted (two transposition events).
2. `load_atac_bins()` (`R/load_atac_bins.R`) — assemble the SCE.
3. `length_normalize()` — reads-per-Mb, matters for variable-width arm-end bins.
4. `filter_sce()` (`R/quality_control.R`) — GC-range, per-bin and per-cell
   count filters.
5. `add_ideal_mat()` (`R/bin_utils.R`) — flag `ideal`/`valid` bins
   (HMMcopy concept: outlier reads, GC outliers, N-frequency, mappability).
6. `add_gc_cor(method = "modal")` (`R/gc_correction.R`) — modal-quantile
   regression GC correction (`gc_cor_modal`); `copykit`/`loess`/`hmm` variants
   also exist.
7. `smooth_counts()` → `calc_ratios()` → `logNorm()` (`R/cnv_tools.R`).
8. `cluster_seurat()` (`R/clustering.R`) — Seurat SNN + Leiden.
9. Optional segmentation: `segment_cnv()` (CBS/DNAcopy) →
   `merge_segments()` (`mergeLevels`) → `identify_normal()` (GMM on
   per-cluster segment SD).

## Two segmentation/CN engines

- **CBS path** (`segment_cnv` + `merge_segments`, `R/cnv_tools.R`) — wired into
  `run_scatools`. Relative copy ratios.
- **Single-cell HMMcopy path** (`add_hmmcopy`, `hmmcopy_singlecell`,
  `params_sc_hmm`, `grab_hmm_res`, `R/hmmcopy_utils.R`) — a full absolute-CN
  engine with multiplier/ploidy search and "halfiness" scoring. Implemented but
  **not currently wired into `run_scatools` or the vignettes.**

## Allele-specific CN (ASCN) path — experimental

`read_vartrix()` (`R/read_vartrix.R`) → `bin_snp_data()`/`get_snp_bidx()`
(`R/bin_snp_data.R`) → `phase_snps()` EM phasing (`R/phase_snps.R`) →
`calc_allelic()`/`calc_ai()` BAF (`R/calc_allelic_imbalance.R`) →
`pseudo_join()` (`R/ascn.R`). `numbat_to_sce()` (`R/nb_to_sce.R`) ingests
Numbat allele data. NOTE: `R/aspcf.R::atac_ascpf()` is an unfinished scratch
stub (references undefined globals, a local ASCAT fork) — do not treat it as
working code.

## Bins & annotation

- `get_tiled_bins()` / `get_chr_arm_bins()` build `GRanges` bins (arm-aware);
  `add_gc_freq()` attaches per-bin GC. Requires a `BSgenome`.
- `get_blacklist()` (ENCODE blacklist), `overlap_genes()` (Ensembl + OncoKB
  cancer-gene annotation).
- Prebuilt `bins_10mb` and a `test_sce` demo object ship in `data/`
  (regenerated by scripts in `data-raw/`).

## Dev environment (IMPORTANT)

- R runs inside Singularity containers via the user's wrappers
  (`R_` / `Rscript_` / `bash_`) — never bare `R`/`Rscript`. See the user's
  global setup. The full dependency stack is installed only in the **R 4.3**
  library; iterate with `Rscript_ -v 4.3`.
- This package does **not** use `renv` (it was removed — renv in a package repo
  hijacks `.libPaths()` and breaks both CI and local dev). Do not reintroduce
  it. If a stray `.Rprofile`/`renv/` reappears, set
  `RENV_CONFIG_AUTOLOADER_ENABLED=FALSE`.

## Conventions

- Roxygen2 (markdown) for all docs; `NAMESPACE` and `man/*.Rd` are generated —
  never edit by hand, run `devtools::document()`.
- SCE assays carry the processing lineage in their names
  (e.g. `counts_gc_modal_smoothed_ratios`); downstream functions default to
  these names.
- Logging currently uses `logger::` (migration to `cli::` is planned).
- `testthat` edition 3 is declared but **no tests exist yet** — add them under
  `tests/testthat/`.
